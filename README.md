# แอปบันทึกการส่งมอบน้ำตาล (Sugar Delivery Record)

แอปมือถือแบบ **PWA (Progressive Web App)** แทนแบบฟอร์มกระดาษ **ML-FM-1610-012 Rev.07 ແບບຟອມບັນທຶກການສົ່ງມອບນ້ຳຕານ** ของบริษัทน้ำตาลมิดลาว

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (หน้าจอ + logic) — ไฟล์เดียวจบ |
| `manifest.webmanifest` | ข้อมูลแอปสำหรับติดตั้งลงหน้าจอ (ชื่อ, ไอคอน, สี) |
| `sw.js` | Service Worker — ทำให้เปิดใช้แบบ offline ได้ |
| `icons/` | ไอคอนแอป 192/512 px + ไอคอน iOS |

## ความสามารถ

- ✅ ติดตั้งลงหน้าจอหลักมือถือ (Android + iPhone) เปิดเต็มจอเหมือนแอปจริง
- ✅ ใช้งาน **offline** ได้หลังเปิดครั้งแรก (เหมาะกับพื้นที่ลานโหลดที่สัญญาณอ่อน)
- ✅ ข้อมูลบันทึกเก็บถาวรในเครื่อง (localStorage) — ปิดแอปแล้วข้อมูลไม่หาย
- ✅ เซ็นลายเซ็นด้วยนิ้ว 4 ฝ่าย — เก็บเป็นรูปภาพจริง
- ✅ ถ่ายรูป/แนบรูปสภาพรถจากกล้องมือถือ
- ✅ ปุ่มพิมพ์ / บันทึกเป็น PDF

## วิธีนำขึ้นใช้งาน (ต้องมี HTTPS จึงติดตั้งลงหน้าจอได้)

เลือกอย่างใดอย่างหนึ่ง:

### ทางเลือก 1 — โฮสต์ฟรี (เร็วสุด แนะนำสำหรับทดลองใช้)
1. สมัคร [Netlify](https://app.netlify.com) หรือ [Vercel](https://vercel.com) (ฟรี)
2. ลากโฟลเดอร์ `SugarDeliveryApp` ทั้งโฟลเดอร์ไปวางในหน้า Deploy
3. ได้ URL เช่น `https://xxxx.netlify.app` — ส่งให้พนักงานเปิดจากมือถือ

### ทางเลือก 2 — เซิร์ฟเวอร์ภายในบริษัท
วางทั้งโฟลเดอร์บน web server (IIS / nginx / Apache) ที่เปิด HTTPS แล้วเข้าผ่าน URL ภายใน

### ทดสอบบนคอมเครื่องนี้ (localhost ถือเป็น secure origin ติดตั้งได้เลย)
```
npx serve "C:\Users\surasakna\Desktop\Project AI\Release Product\SugarDeliveryApp"
```
แล้วเปิด `http://localhost:3000` ใน Chrome/Edge

## วิธีติดตั้งลงหน้าจอมือถือ (บอกพนักงาน)

**Android (Chrome):** เปิด URL → จะมีแบนเนอร์เขียว "ຕິດຕັ້ງແອັບລົງໜ້າຈໍ" กดปุ่ม **ຕິດຕັ້ງ** (หรือเมนู ⋮ → *Add to Home screen*)

**iPhone (Safari):** เปิด URL → กดปุ่ม Share ⬆️ → **Add to Home Screen (เพิ่มลงหน้าจอโฮม)**

## ข้อจำกัดของเวอร์ชันนี้ (ขั้นถัดไปถ้าต้องการ)

- ข้อมูลเก็บ**ในเครื่องแต่ละเครื่อง** ยังไม่ sync ขึ้นเซิร์ฟเวอร์กลาง — ถ้าต้องการฐานข้อมูลรวม/รายงาน ต้องต่อ backend (เช่น Google Sheets API, Supabase, หรือ server ภายใน)
- การพิมพ์ PDF ใช้หน้าจอสรุป ยังไม่ใช่ layout เหมือนฟอร์มกระดาษ 100%
- ยังไม่มีระบบ login / กำหนดสิทธิ์ผู้ใช้
